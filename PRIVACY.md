# Privacy policy for autotube

_Last updated: 10 October 2026_

autotube is a personal tool that uploads videos to its owner's own YouTube channel. It is used only by
the owner of this repository.

**What it accesses.** With the owner's permission, autotube uses the YouTube Data API
(`youtube.upload` scope) only to upload videos to the owner's channel, and the public YouTube Data API
to look up public video statistics for niche research.

**What it stores.** The Google login token is stored only as an encrypted GitHub Actions secret in
this repository. autotube does not collect, sell or share any personal data, and it does not access
anyone else's account or data.

**Removing access.** Access can be revoked at any time at <https://myaccount.google.com/permissions>.

autotube's use of information received from Google APIs adheres to the
[YouTube API Services Terms of Service](https://www.youtube.com/t/terms) and the
[Google Privacy Policy](https://policies.google.com/privacy).

**Contact.** Open an issue on this repository.
